# DueCue resume bullets

- Built DueCue, a full-stack adaptive academic deadline assistant using React, Express, Prisma, and PostgreSQL that syncs course tasks, calculates personalized start windows, and provides proactive reminder previews.
- Designed a provider-based ingestion system with simulated Canvas data, transactional external-ID upserts, deadline-change detection, and task/sync audit logs to support future LMS integrations.
- Implemented a deterministic, confidence-weighted recommendation engine that combines task type, effort, difficulty, points, urgency, and user feedback to adapt reminder lead times.
- Shipped a recruiter-ready demo mode with staged source changes, private ICS calendar export, responsive dashboard UX, and safe dev authentication without storing school credentials.
