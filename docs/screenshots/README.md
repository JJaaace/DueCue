# DueCue screenshot checklist

This folder intentionally contains no captured student data. Add the final portfolio images here before publishing a portfolio post or updating the repository README.

Capture these PNGs at a desktop width of approximately 1440px:

1. `home.png` — Home with Next Cue, start-today rows, and the subtle demo workspace state.
2. `task-drawer.png` — An opened task drawer showing the explanation, timing signals, and feedback controls.
3. `sync-changes.png` — Stage 2–4 demo data with Recent Changes visible.
4. `import.png` — The safe import page and its user-authorized connection paths.
5. `notification-settings.png` — Reminder recipients with clearly marked demo verification.
6. `email-feedback.png` — The branded feedback confirmation page after a test preview link.

Before capture, use **Reset recruiter demo** and avoid including real email addresses, private feed URLs, database errors, or access tokens.
